Home/Support

Ask in the open, disclose in private

There is no commercial support or response-time SLA. The project is maintained on a best-effort basis under Apache-2.0.

I have a question

Use GitHub Discussions for usage, integration and design questions. Search existing discussions first.

Open Discussions

I found a bug

Open an issue using the bug report form. Include the commit or version, API level, expected and actual behavior, and the smallest synthetic reproduction.

Open an issue

I found a vulnerability

Use private vulnerability reporting. Never open a public issue with exploitable detail or sensitive evidence.

Report privately

I want an integration reviewed

Open an integration report with the host framework, supported platforms, privacy policy summary and the exact test commands you ran.

Open an issue
!

Never include real data. Do not paste real reports, screenshots, credentials, personal data or private application code into an issue or discussion. Use synthetic reproductions. If the problem is security-sensitive, use the private channel instead.

No commercial SLA

No commercial support, response-time SLA, bounty or hosting service is offered. Maintainers review public issues and private advisories when capacity allows. Adoption and production operation remain the host's responsibility.
