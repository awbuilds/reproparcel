Read the typed outcome first

ReproParcel reports failure as a category, not a stack trace. Start with the outcome code, then check the corresponding boundary.

Reporter returns NotInitialized, Disabled or Unsupported

  • Call ReproParcel.initialize(context, config) explicitly.
  • setEnabled(true) is required; the default is disabled.
  • For Compose hosts use ReproParcelCompose.showReporter(activity, surfaceId) after the runtime is enabled. The Android-only ReproParcel.showReporter stub returns Unsupported until a Compose launcher is registered.

Screenshot is omitted

  • Confirm CapturePolicy.screenshotEnabled = true and the current surface ID is in eligibleSurfaces.
  • A FLAG_SECURE window is always omitted; raw PixelCopy success is not proof of privacy.
  • Changing layout or scroll during capture can invalidate the attempt.
  • Very large windows can be omitted by the 24 MiB bound.
  • A text-only report remains valid. Do not weaken the policy to force an image.

Draft save fails

CodeCause and response
ENCRYPTION_UNAVAILABLEKeystore key invalidated or device lock changed. The reporter may keep an in-memory draft; there is no plaintext fallback.
LIMIT_EXCEEDED10-report / 25 MiB quota reached. Delete old drafts explicitly.
STORAGE_FAILEDDisk or IO failure. Check free space; do not retry as plaintext.

Parcel rejected by the desktop tool

Run reproparcel validate file.reproparcel --json. Common codes:

CodeMeaning
CHECKSUM_MISMATCH / SIZE_MISMATCHCorrupt or modified archive.
INVALID_PATH / SYMLINK / DUPLICATE_ENTRYHostile or unsupported ZIP structure.
UNREFERENCED_ENTRYManifest and container disagree.
IMAGE_MEMORY / IMAGE_DIMENSIONSPNG exceeds the consumer budget.
UNSUPPORTED_SCHEMAThe reader does not support the manifest version.

Do not bypass validation or extract into a shared directory.

MCP returns no reports

  • Start with mcp --root <directory> containing .reproparcel files.
  • The server accepts report IDs, not arbitrary paths.
  • Invalid or corrupt parcels are skipped by the indexer; validate them separately.
  • Read-only MCP is not an egress guarantee; choose a local client for sensitive evidence.
