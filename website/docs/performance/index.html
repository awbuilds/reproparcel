Measured on one low/mid-range device

These are local measurements, not a universal performance guarantee. Results come from the release benchmark variant.

Documentation

Device and setup

Android 12 / API 31, arm64-v8a, 8 cores, 3.7 GiB RAM, 1080×2460 at 400 dpi. Release benchmark variant, wireless ADB, 98–100% battery, battery about 33.8–35 °C.

Interpretation

  • Synchronous SDK initialization is well below the proposed 10 ms startup sub-budget.
  • Capture and trigger-to-composer are within the proposed 2 s and 300 ms budgets on this device.
  • The paired jank result passes the 5% p95-duration and 1 percentage-point deadline-miss gates.
  • The APK difference includes the reporter UI, so the SDK core and Android portion is below the reported ~0.40 MiB.

Limitations

  • Capture and collector measurements use debug instrumentation. Release timing should be no worse but is not separately instrumented.
  • The full cold-start comparison is too noisy on this device to resolve a 10 ms difference; the trace section is the stable SDK sub-budget measure.
  • A current physical device, physical API 26/30 rows and a multi-hour thermal/ANR soak are not available.
  • These measurements do not cover every OEM, Compose version, surface or accessibility setting.
