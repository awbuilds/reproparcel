Known limitations

  • Automatic Compose or accessibility extraction is not shipped; explicit host registration is the v1 baseline.
  • Foreground shake is optional and implemented; the manual entry point remains the guaranteed control.
  • The full temporal frame-binding proof and several race fixtures remain outstanding. Image capture is fail-closed but not certified for every surface.
  • Release smoke uses the minified app with UI automation; the release JUnit test-APK path is unstable under R8.
  • TalkBack manual verification and a longer thermal/ANR soak remain open.
