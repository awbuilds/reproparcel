# Community standards

ReproParcel is a public project for people with different backgrounds, skill
levels and privacy requirements. Participation must stay respectful and
constructive.

## Expected behavior

- Discuss ideas and code, not people.
- Assume good faith and ask clarifying questions before escalating.
- Respect privacy: never post real reports, credentials, personal data or
  private application code.
- Keep issues and pull requests focused, reproducible and safe to publish.
- Give credit for other people's work and follow the project licenses.

## Unacceptable behavior

- Personal attacks, insults, threats or intimidation.
- Discriminatory language or conduct.
- Publishing someone else's private information without permission.
- Deliberately disruptive, spammy or bad-faith participation.
- Pressuring maintainers to merge, release or disclose something before the
  project's gates are satisfied.

## Scope

These standards apply to issues, pull requests, discussions, code review,
commit messages, documentation and other project spaces.

## Reporting and moderation

Use GitHub's repository moderation/report tools for behavior that violates these
standards. For a sensitive security concern, use the private vulnerability
reporting channel described in [SECURITY.md](SECURITY.md); do not post sensitive
evidence publicly.

Maintainers may edit or remove content, lock threads, reject contributions or
restrict participation when needed to keep the project safe and productive.
Enforcement decisions are recorded when they affect project governance.
