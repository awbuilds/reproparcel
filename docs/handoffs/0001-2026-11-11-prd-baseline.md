## Decisions and corrections

- Sentry already offers Android feedback, shake and replay, including supported self-hosted configurations. Differentiate on portable/local/backend-independent evidence rather than claiming no competitor exists.
- Compose `RootForTest` is test-oriented. Ship explicit host registration unless automatic extraction passes a public-API minified-release compatibility experiment.
- Interpret “try/catch everywhere” as every recoverable SDK boundary, not empty catches, swallowed coroutine cancellation or false recovery from native aborts/VM failure.
- Baseline license is AGPL-3.0-only, explicitly distinguishable from an adopter's or-later option. No proprietary linking exception, dual licensing or copyright assignment is implied.
- Manual local export is the v1 delivery path. Tracker credentials/attachment routing and a relay are future design, not guessed SDK behavior.
