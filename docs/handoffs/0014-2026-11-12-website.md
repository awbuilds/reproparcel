# 0014 — 2026-11-12 — Static project website

## Objective and scope

Build a complete project website in `website/`: home, about, privacy policy,
terms of service, changelog, roadmap, security, contributing, license, support,
a seven-page documentation section, 404, robots, sitemap and web manifest.
Static HTML with one stylesheet and one script. No npm packages, no build step,
no external requests. Committed and pushed to `dev` at the maintainer's explicit
instruction; nothing was deployed.

## Starting state

`dev` with the Apache-2.0 relicensing work present in the working tree. No tag,
release, deployment or `main` branch. The `website/` directory did not exist.

## Work completed

- Added 18 HTML pages under `website/` with shared header, control strip, footer,
  dark/light themes and responsive layout.
- Established a visual world: an evidence dossier. Dark archive-green ground,
  bone ink, stamped yellow seals, hairline rules, paper exhibit plates and square
  corners. No gradient text, icon-card grids, pill buttons or eyebrow labels.
- Self-hosted three SIL OFL typefaces as Latin woff2 subsets with their license
  texts: Archivo (display and UI, variable width), Source Serif 4 (long-form
  prose) and JetBrains Mono (code, data and artifact labels). No hosted font
  stylesheet is requested at runtime.
- Rebuilt the home page around the artifact itself: a labelled parcel object
  with a pressed stamp, a manifest ledger, a four-station chain of custody,
  numbered exhibit plates, an interactive redaction document, a measurement
  ledger, a PASS/BLOCKED release record and a documentation index.
- The redaction document is the second signature element: four black bars on a
  paper sheet reveal the withheld category on hover or keyboard focus, so the
  privacy model is demonstrated rather than asserted.
- Added `website/assets/css/site.css` (design tokens, two themes, print and
  reduced-motion handling, themed selection, caret and scrollbars).
- Added `website/assets/js/site.js` (theme persistence, mobile navigation, copy
  buttons). Theme is applied before paint; no inline script or inline style is
  used, so the per-page CSP meta tag holds.
- Added a restrictive CSP meta tag to every page:
  `default-src 'self'`, local images only, `connect-src 'none'`,
  `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`.
- Content pages mirror the repository documents and link back to the source
  file. The repository remains authoritative.
- Legal pages: a privacy policy that separates this website (no cookies, no
  analytics, no third-party requests) from the SDK (off by default, host-owned
  policy) and a terms page that covers Apache-2.0, pre-release status, no SLA,
  no warranty, trademark limits, contributions and governing law.
- License content reflects ADR 0015: Apache-2.0, express patent grant,
  NOTICE/attribution and modification-marking obligations, no copyleft, no
  trademark grant, and the historical AGPL-3.0-only note.
- Copied `logo.svg` and the social preview plus the four synthetic screenshots
  from `docs/assets/` into `website/assets/`.
- Added `scripts/check_website.py`: required files, internal links and assets,
  local-only resource references, external-host allowlist, CSS `url()` resolution
  and no remote stylesheet URLs, CSP/skip-link/main/description/heading checks,
  no inline scripts, and required status/privacy/legal phrases.
- Added `website/README.md` with preview, deploy, structure, type system,
  provenance and editing rules.
- Added `.github/workflows/pages.yml` — **manual `workflow_dispatch` only**, with
  the push trigger commented out. The deploy job was never run.
- Registered the new PNGs and the three woff2 files in
  `scripts/allowed-binary.txt`, added `website/README.md` to
  `scripts/check_docs.py`, and added the website check and markdown lint to
  `.github/workflows/docs.yml`.
- Updated `docs/PROJECT_STATE.md` and `docs/README.md`.

The first browser pass surfaced two real defects that were fixed before the
final run: inline `style` attributes blocked by the CSP, and footer navigation
links missing the relative prefix on subpages. The second pass caught the
docs breakpoint overflowing horizontally because the grid column used an
`auto` minimum; it now uses `minmax(0, 1fr)` and the page reports zero overflow.

Glyph coverage was checked against the Latin font subsets. Arrow and check
glyphs from the original draft (`→`, `←`, `✓`) are not in the subset and were
replaced with ASCII or removed; the only non-ASCII characters left are dashes,
quotes and an ellipsis, all inside the subset.

## Privacy, reliability, API and license impact

- No Android module, public API, schema, runtime, desktop tool or relay code
  changed. No Gradle or npm dependency was added.
- The website makes no analytics, cookie, CDN or third-party request. Typefaces
  are self-hosted from the repository, so the page loads no font provider. Only
  the GitHub Pages host sees standard request data.
- All new binary assets are copies of already-reviewed repository screenshots
  and the social preview, plus three woff2 font subsets. All are allowlisted.
- The fonts are third-party assets under the SIL Open Font License 1.1. Their
  license texts ship beside the binaries in `website/assets/fonts/`. This is not
  a change to the project's own Apache-2.0 license.
- Content uses no personal information, real reports, credentials or private
  adopter references.
- Apache-2.0 SPDX headers are present in the CSS, JS, checker, workflow and
  HTML comments where applicable.

## Incomplete work and blockers

- `privacy/` and `terms/` are plain-language project drafts, not legal advice.
  Qualified legal review remains a blocked release gate; have counsel review
  both pages before publishing under a real identity or domain.
- GitHub Pages is not enabled. `pages.yml` has never run, so its action
  versions and permissions are unverified. Only `workflow_dispatch` is enabled.
- No custom domain or `CNAME` file exists. The canonical origin is
  `https://awbuilds.github.io/reproparcel/`. A custom domain requires updating
  the `SITE` constant used for canonical/OG URLs, `sitemap.xml`, and the
  absolute paths in `404.html`.
- The site is a manual mirror, not generated. Documentation drift is possible;
  the provenance table and required-phrase checks reduce but do not eliminate
  it.
- Screenshots are duplicated between `docs/assets/` and `website/assets/` to
  keep the published artifact self-contained.
