## Privacy, reliability and compatibility impact

Drafts are encrypted with no plaintext fallback; tests assert ciphertext does
not contain the synthetic marker. The review screen shows the flattened image
and selects no consent checkbox by default. Secure windows are omitted before
PixelCopy and re-checked after. Sharing reports only chooser launch, never
receipt. No real data or private application code was used.
