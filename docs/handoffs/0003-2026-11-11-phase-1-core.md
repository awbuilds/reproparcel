## Privacy, reliability and compatibility impact

Screenshot/semantic collection remains off by default. Invalid config and
provider failures return typed results; provider exceptions are not surfaced to
the host. Cancellation is rethrown and disabling cancels SDK-owned jobs. No
real reports, screenshots, credentials or private application code were used.
No new permission or network dependency was added to the runtime.
