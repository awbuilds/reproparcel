## Protected window policy (API 37.2)

Observed:
respect=true -> SECURE_WINDOW FLAG_SECURE is set; capture omitted

Raw experiment (spike-only bypass):
respect=false -> SUCCESS bytes=10368000 center=#FFFAFAFA

The raw observation is why the production SDK must pre-check FLAG_SECURE and
must not expose a caller-controlled bypass.

## Limitation

The release JUnit test-APK path was unstable under R8, so this smoke used the
minified app with UI automation. A stable release-device harness is Phase 5
work. The app proguard file now contains no broad first-party/Kotlin keep rules.
