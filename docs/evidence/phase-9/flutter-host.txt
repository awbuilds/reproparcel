# Phase 9 — Flutter Android host and native bridge evidence

Date: 2026-11-11
Host: `flutter/host_app`, Flutter/Dart 3.12, Android API 37.2 emulator.

## Build

```text
cd flutter/host_app
flutter pub get
flutter build apk --debug
✓ Built build/app/outputs/flutter-apk/app-debug.apk
```

APK installed and launched on the API 37.2 emulator.

## Native plugin

`flutter/reproparcel_flutter/android/` is a real Android Flutter plugin
(`ReproParcelFlutterPlugin`) that forwards initialize/enable/breadcrumb/log/
reporter/delete calls to the Android runtime. It uses the local Maven candidate
artifacts and the Compose reporter.

## Tests

```text
flutter test
All tests passed! (host widget test)

flutter test integration_test/plugin_test.dart -d emulator-5554
All tests passed!
```

The device integration test asserts:

- native `initialize` succeeds;
- `setEnabled(true)` succeeds;
- a safe synthetic breadcrumb is accepted;
- local draft/export deletion succeeds;
- `showReporter` returns `success` and opens the reporter activity.

Raw logs: `flutter-widget-test.txt`, `flutter-plugin-test.txt`.

## Limits

- One consumer host only; Phase 9 still requires actual adopter demand and

- No Flutter iOS plugin, platform-view matrix, release-performance evidence,
