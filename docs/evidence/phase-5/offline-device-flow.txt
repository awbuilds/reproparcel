## Flow

1. Launch release sample with airplane mode enabled.
2. Enable SDK explicitly.
3. Open reporter.
4. Enter synthetic description `SyntheticOffline`.
5. Review the text-only report and confirm the exact content.
6. Save through the SAF `CreateDocument` picker to Downloads.
7. Pull the synthetic parcel.
8. Validate, inspect and render it with the offline desktop CLI.

The synthetic export was removed from the emulator afterwards. This verifies
G-06 on one local device; it does not verify physical-device or multi-client
coverage.
