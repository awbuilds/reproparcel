# Phase 7 — React Native Android host build and bridge evidence

Date: 2026-11-11
Host: `react-native/ReproParcelHost`, React Native 0.88.1, Android API 37.2 emulator.

## Build

```text
cd react-native/ReproParcelHost/android
./gradlew :app:assembleRelease
BUILD SUCCESSFUL
```

Release APK installed and launched on the API 37.2 emulator.

## Observed flow

```text
ReproParcel RN host
Synthetic integration host. No real report data.
Initialized disabled
ENABLE SDK
RECORD BREADCRUMB
OPEN REPORTER
DELETE LOCAL REPORTS
```

- `ENABLE SDK` → `Enabled`.
- `RECORD BREADCRUMB` → `Breadcrumb recorded`.
- `OPEN REPORTER` → reporter activity opened with the form, image omission
  state and `Edit image` action (screenshot policy enabled in the synthetic
  host).
- Entering a synthetic description, selecting `Edit image`, and tapping
  `Review image report` reached `Exact final content`.

The bridge now dispatches `showReporter` to the UI thread and returns a typed
result (`success`, `disabled`, `host_unavailable`, `failure`, ...) instead of a
bare boolean.

## Limits

- One consumer host; the Phase 7 exit still requires two distinct consumer
  examples.
- No Hermes/profile matrix, mixed native/JS screen matrix or Expo config plugin.
- No real report data was used. Generated build/cache directories and local
  debug keystores are ignored.
