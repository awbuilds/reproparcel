# Assets

- `brand/` — original ReproParcel logo, banner and social preview. The mark is
  project-owned vector geometry; no third-party artwork is included.
- `badges/` — local static SVG badges used by the README. The CI badge is the
  GitHub Actions badge for this repository.
- `screenshots/` — synthetic sample-app screenshots used for documentation. They
  contain no real reports, personal data or private application content.

The reporter screenshots were taken with a documentation-only build of the same
synthetic UI because the shipped reporter marks its window secure and blocks
screen capture. The viewer screenshot uses a synthetic parcel.

Binary art is reviewed before being added to `scripts/allowed-binary.txt`.
