# Support

## I have a question

Use [GitHub Discussions](https://github.com/awbuilds/reproparcel/discussions)
for usage, integration and design questions. Search existing discussions first.

## I found a bug

Open a GitHub issue using the bug report form. Include:

- the SDK commit or version;
- Android API level and device class;
- expected and actual behavior;
- the smallest synthetic reproduction;
- relevant sanitized logs or omission reasons.

Do **not** include real reports, screenshots, credentials, personal data or
private application code. If the problem is security-sensitive, use the private
channel below instead.

## I found a vulnerability

Use GitHub's private vulnerability reporting for `awbuilds/reproparcel`. See
[SECURITY.md](SECURITY.md). Do not open a public issue with exploitable detail
or sensitive evidence.

## I want an integration reviewed

Open an integration report issue with the host framework, supported platforms,
privacy policy summary and the exact test commands you ran. A maintainer can
comment on the public contract; production adoption remains the host's
responsibility.

## I need a commercial SLA

No commercial support, response-time SLA, bounty or hosting service is offered.
The project is maintained on a best-effort basis under AGPL-3.0-only.
