# Changelog

All notable changes are documented here. This project is not yet released.

## [Unreleased]

### Added

- Phase 0 public-repository foundation, AGENTS.md hygiene rule and AGPL-3.0-only
  license.
- Gradle/Android toolchain baseline and disposable capture-lab spike.
- Line-level PRD traceability, audit tooling, ADRs, threat-model draft and
  Phase 0 evidence.
- PixelCopy capture, opaque mask, protected-window omission and rotation tests
  on API 26/30/37 emulators.
- Phase 1 module graph, schema v1, typed runtime, allowlisted redaction, bounded
  buffers, state machine and synthetic sample.
- 37 core JVM tests, 11 runtime tests and 2 sample UI tests on API 26/30/37.
- CI with public hygiene, dependency allowlist, API check, schema conformance
  and lint.

### Known limitations

- No stable release, Maven publication, tag or GitHub Release.
- External adopter validation, physical-device performance and independent
  security/legal review remain blocked.
- The production SDK modules, encrypted drafts, reporter UI and desktop tools
  are not implemented yet.
